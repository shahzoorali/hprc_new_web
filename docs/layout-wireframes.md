# Layout Wireframes (Textual)

These notes capture the structural wireframes for each top-level page based on the information architecture.

## Home (`/`)

1. **Hero**: Full-width background, headline “Hyderabad Polo & Riding Club”, CTA buttons (“Apply for Membership”, “Explore Programmes”).
2. **Value Pillars**: Three column layout (Equestrian Excellence, Sports Centre, Hospitality).
3. **Featured Programmes**: Card grid linking to Riding & Polo pages.
4. **Sports Centre Preview**: Horizontal scroll of facility cards.
5. **Events & Media Spotlight**: Two-column layout featuring upcoming event and latest news/blog.
6. **Membership CTA**: Highlight benefits + button.
7. **Footer**: Global footer component.

## About

1. Hero with breadcrumb.
2. Club Overview: Two-column text + imagery.
3. Mission, Vision, Values: Split sections with contrasting backgrounds.
4. Managing Committee: Responsive grid of profile cards.
5. Heritage Timeline: Horizontal scroll / stacked timeline component.

## Programmes

1. Overview hero with CTA to schedule visit.
2. Programme cards segmented by level (Beginner, Intermediate, Advanced, Equestrian).
3. Pricing tables for each programme.
4. Knowledge section embedding “Horse Riding Benefits” excerpt.
5. CTA banner for membership enquiries.

## Sports Centre

1. Hero with facility collage.
2. Facility grid (Tennis, Badminton, Squash, etc.) using icon + description + timings.
3. Pricing table accordion (per sport).
4. Coaching availability callout.
5. Packages comparison (Gold vs Platinum).

## Hospitality

1. Hero featuring dining/banquet imagery.
2. Venue spotlight cards (Chukkers, Snaffles Bistro, Banquets, Luxury Rooms).
3. Amenities list (services, capacity, special features).
4. Testimonials placeholder.

## Membership

1. Hero with persuasive copy.
2. Steps to apply (timeline or numbered list).
3. Membership benefits grid.
4. Member services links (Login, Pay Now).
5. FAQ accordion.

## Events & Media

1. Hero with event photography.
2. Upcoming events list (cards, date badges).
3. Past events highlights + gallery.
4. News/Blog preview with read more.
5. Newsletter signup CTA.

## Contact

1. Hero with map background.
2. Contact details (address, phone, email) in cards.
3. Embedded map component.
4. Enquiry form placeholder.
5. Operating hours / directions.
